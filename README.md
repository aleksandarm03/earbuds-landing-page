# 🎧 Earbuds Landing Page

A modern and responsive landing page for a fictional brand of wireless earbuds, built to showcase clean UI design and front-end development skills.

🌐 **Live Preview**  
[Click here to view the site](https://aleksandarm03.github.io/earbuds-landing-page/)

## 📌 Features

- ✅ Hero section with promotional call-to-action  
- ✅ Product showcase with sleek visuals  
- ✅ Feature highlights with minimalist icons  
- ✅ Customer testimonials section  
- ✅ Clean footer with social and contact links  
- ✅ Fully responsive design – mobile, tablet, and desktop ready

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (vanilla)
